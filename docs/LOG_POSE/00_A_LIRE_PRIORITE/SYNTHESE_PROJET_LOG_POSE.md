# Synthèse projet — Vogue Merry / Log Pose

## Identité

Projet : Vogue Merry  
Outil : Log Pose  
Destinataire principal : Mateo  

Phrase d'accueil validée :

**Log Pose**  
**Cap projet, décisions, versions.**

Devise discrète :

*Garder le cap, protéger la mémoire, avancer avec son équipage.*

## Objectif

Log Pose aide Mateo à garder le cap dans plusieurs projets informatiques / EPM sans devoir tout porter mentalement.

L’outil sert à retrouver rapidement :
- une décision ;
- une règle de calcul ;
- une action ;
- un blocage ;
- un document ;
- une version validée ;
- une information issue d’une réunion.

## Principe produit

Log Pose n’est pas une simple application de compte-rendu.

C’est une mémoire projet structurée et versionnée :
- on capte la réunion ;
- on marque les moments importants ;
- on produit un document exploitable ;
- on garde les versions précédentes ;
- on valide les versions importantes ;
- on retrouve l’information plus tard.

## Structure V1

### Accueil

L’accueil doit répondre à :

**Qu’est-ce que j’ai à reprendre ?**

Éléments :
- recherche : “Retrouver une décision, une règle, une action…” ;
- bloc “À reprendre” ;
- bloc “Projets”.

### Projet

Dans un projet, Mateo doit voir :
- en un coup d’œil ;
- à reprendre dans ce projet ;
- décisions ;
- règles de calcul ;
- actions ;
- blocages ;
- documents ;
- versions ;
- historique ;
- réunions.

### Mode réunion

Le bloc réunion est plié par défaut.

Quand il est ouvert, il contient :
- type de réunion ;
- présents ;
- absents / excusés ;
- objectif ;
- ordre du jour ;
- audio ;
- notes ;
- transcription ;
- marqueurs métier ;
- création du document.

## Marqueurs de réunion

Déroulé :
- ouverture ;
- présents ;
- absents / excusés ;
- objectif de la réunion ;
- ordre du jour ;
- point précédent.

Marqueurs métier :
- décision ;
- règle de calcul ;
- action ;
- blocage ;
- écran / parcours ;
- données / imports ;
- méthode ;
- question ouverte ;
- validation métier.

## Audio et transcription

Flux cible :

Audio  
↓  
Transcription  
↓  
Document exploitable  
↓  
Version validée  

L’audio garde la matière brute.  
La transcription transforme la parole en texte.  
Les marqueurs donnent le sens métier.
