# Décisions validées — Log Pose

## Nom et positionnement

- Projet global : Vogue Merry
- Outil : Log Pose
- Destinataire principal : Mateo

Log Pose aide Mateo à garder le cap dans ses projets.

## Accueil

Décision validée :

L’accueil n’est pas une page de présentation.  
C’est une page de reprise du travail.

Ordre principal :
1. Recherche
2. À reprendre
3. Projets

Phrase d’accueil :

Log Pose  
Cap projet, décisions, versions.

Placeholder recherche :

Retrouver une décision, une règle, une action…

## À reprendre

Le bloc “À reprendre” doit afficher :
- le nom du projet ;
- la chose à traiter ;
- un statut discret.

Le nom du projet doit permettre d’ouvrir le projet.

## Réunion

Le bloc réunion doit être plié par défaut.

Quand il est ouvert, il devient un mode réunion complet avec :
- audio ;
- transcription ;
- notes ;
- déroulé ;
- marqueurs métier.

## Chapeau de paille

Le chapeau de paille reste :
- discret ;
- détouré ;
- sans rond ;
- avec effet vent / mouvement ;
- comme s’il était de passage.

## Documents

Interface Log Pose : esprit Vogue Merry discret.
