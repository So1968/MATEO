# Intention cadeau — Vogue Merry / Log Pose

## Phrase de présentation validée

Vogue Merry, c’est le navire.  
Log Pose, c’est l’outil de navigation.

Il aide Mateo à garder le cap dans ses projets,  
pour ne pas tout porter seul,  
et garder de l’énergie pour ce qui compte aussi hors du travail :  
sa vie de jeune papa.

## Sens du projet

Vogue Merry / Log Pose est un cadeau utile, personnel et professionnel.

L’objectif n’est pas seulement de créer un outil efficace.

L’objectif est d’aider Mateo à :
- alléger sa charge mentale ;
- retrouver le fil de ses projets ;
- sécuriser les décisions et les versions ;
- savoir quoi reprendre ;
- ne pas porter seul toute la mémoire projet ;
- garder de l’énergie pour sa vie personnelle.

## Métaphore validée

Vogue Merry = le navire  
Log Pose = l’outil de navigation  
Les projets de Mateo = les îles à suivre  
Les réunions = les escales  
Les décisions = les caps validés  
Les versions = les cartes conservées  

## Phrase courte

Log Pose est le compagnon de navigation des projets de Mateo.
Il l’aide à reprendre le bon sujet, retrouver la bonne information et sécuriser ce qui a été décidé.
