# Pitch présentation Mateo — Version 2

## Ouverture

Vogue Merry, c’est le navire.  
Log Pose, c’est l’outil de navigation.

Il aide Mateo à garder le cap dans ses projets,  
pour ne pas tout porter seul,  
et garder de l’énergie pour ce qui compte aussi hors du travail :  
sa vie de jeune papa.

## Promesse

Log Pose aide Mateo à :
- retrouver une décision ;
- retrouver une règle de calcul ;
- retrouver une action ;
- savoir quoi reprendre ;
- suivre une réunion ;
- capter l’audio ;
- préparer une transcription ;
- produire un document exploitable ;
- garder des versions ;
- sécuriser ce qui a été validé.

## Vocabulaire de présentation

Utiliser :
- Alléger la charge mentale
- Retrouver le fil sans effort
- À reprendre
- Trame de réunion
- Cap projet, décisions, versions
- Mémoire projet
- Version validée

Éviter :
- Ne plus tout garder dans la tête
- Journal de bord
- Ordre de réunion
- Compte-rendu partout
- Vocabulaire Git
