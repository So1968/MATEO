# Déroulé de réunion et marqueurs

## Principe

Le mode réunion doit suivre le déroulement naturel d’une réunion.

Il ne doit pas seulement capter des décisions isolées.

## Déroulé de réunion

Marqueurs de déroulé :
- Ouverture
- Présents
- Absents / excusés
- Objectif de la réunion
- Ordre du jour
- Point précédent

## Marqueurs métier

- Décision
- Règle de calcul
- Action
- Blocage
- Écran / parcours
- Données / imports
- Méthode
- Question ouverte
- Validation métier

## Exemple de trace

09:58 — Présents — Mateo, Nora, Alex.  
09:59 — Absents / excusés — Samia excusée.  
10:00 — Objectif — Valider la règle de marge et identifier les impacts.  
10:42 — Méthode — Utiliser nos propres réunions comme terrain de test avant déploiement à Mateo.

## Règle produit

Les marqueurs structurent la réunion pendant qu’elle se déroule.

La transcription garde la parole.  
Les marqueurs donnent le sens métier.
