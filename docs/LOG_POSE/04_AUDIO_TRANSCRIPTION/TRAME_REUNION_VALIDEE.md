# Trame de réunion validée — Log Pose

## Terme validé

Utiliser : Trame de réunion

Ne pas utiliser :
- ordre de réunion ;
- déroulé comme titre principal.

## Principe

La trame de réunion guide Mateo pendant la réunion.

Elle donne une progression naturelle, mais elle ne bloque jamais l’utilisateur.

Mateo peut cliquer à tout moment sur un marqueur si la réunion change de direction.

## Ordre proposé

1. Ouverture
2. Participants
3. Contexte
4. Ordre du jour
5. Travail métier
6. Validation
7. Clôture

## Participants

Dans la partie Participants, prévoir :
- présents ;
- absents / excusés ;
- présentation participant ;
- rôle participant ;
- nouvel intervenant.

Objectif :
savoir qui est là, qui parle, quel est son rôle, et quelle information il porte.

## Marqueurs métier accessibles à tout moment

- Décision
- Règle de calcul
- Action
- Blocage
- Méthode
- Écran / parcours
- Données / imports / interfaces
- Question ouverte
- Validation métier

## Exemple de trace

09:32 — Présents — Mateo, Nora, Alex.  
09:34 — Présentation participant — Nora, référente métier finance.  
09:35 — Rôle participant — Alex intervient sur les imports et interfaces.  
10:42 — Méthode — Tester l’outil sur nos propres réunions avant déploiement.  

## Phrase produit

Le mode réunion de Log Pose est un rail de navigation :
il guide la progression, mais laisse l’équipage changer de cap quand la réunion l’exige.
