# Proposition — Fiches contacts / personnes

## Idée

Ajouter à Log Pose une mémoire des personnes liées aux projets.

Chaque personne peut être reliée :
- aux projets ;
- aux réunions ;
- aux décisions ;
- aux actions ;
- aux validations ;
- aux blocages.

## Exemple de fiche

- Nom
- Rôle
- Entreprise
- Téléphone
- Email
- Notes utiles
- Réunions liées
- Décisions associées
- Actions attendues
- Validations données

## Objectif

Ne pas seulement savoir qui participe.

Pouvoir retrouver :
- qui a dit quoi ;
- qui valide quoi ;
- qui doit faire quoi ;
- qui est attendu sur quel sujet.

## Développement possible

À terme :
- import depuis contacts Microsoft ;
- synchronisation possible ;
- copie serveur exploitable ;
- lien avec participants de réunion.
